# 本地音乐中转（在自己电脑上跑）

## 为什么需要它

App 是纯前端，浏览器不能直接请求网易云/酷狗（CORS 限制），所以导入必须经中转。
云端中转（Cloudflare）出口在境外，网易云/酷狗**不给境外 IP 返回播放直链**，
于是导入的歌有封面、有歌词，但**点播放没声音**。

把同一个中转跑在你自己电脑上，出口就是你的宽带 IP（境内），接口会正常返回播放直链。

## 三步使用

### 1. 装 Node

- 打开 https://nodejs.org/ 下载 LTS 版本，一路下一步安装即可
- 装完在终端输入 `node -v`，能显示版本号（18 以上）就行

### 2. 运行中转

把本目录下的 `server.js` 放到任意文件夹，在该文件夹里打开终端，执行：

```bash
node server.js
```

看到下面的提示就说明启动成功：

```
Eunoia 本地音乐中转已启动
地址：http://127.0.0.1:8787
```

自定义端口：`node server.js --port=9000`
允许局域网其它设备访问：`node server.js --lan`

### 3. 在 App 里填入

进入 **设置 → 音乐 → 解析服务**，填：

```
http://127.0.0.1:8787
```

点「保存」，再点「测试连接」，显示「连接成功」即可。然后回到「链接导入」粘贴歌曲链接导入。

## 注意事项

- **必须在电脑上打开 Eunoia 使用**：`127.0.0.1` 指的是运行中转的那台机器本身。
  在手机上填局域网 IP（如 `http://192.168.1.5:8787`）会被浏览器以「混合内容」拦截。
- **导入完就可以关掉**：播放用的是已经写进数据库里的地址，不需要它常驻。
  但要注意网易云的直链带临时令牌，**会过期**（实测一天前取的地址现在已经 403）。
- 想在手机上听：电脑导入后，在「内存数据 → 全部导出」备份，再到手机上导入同一个备份，
  音频地址会一起过去（同样受有效期限制）。
- 这个工具只在本地监听、不存任何数据、不上传任何内容，随时可以关掉。
